# 🚀 Lunar Dash — Moon to Earth Parkour

A browser-based side-scrolling parkour game where you guide an astronaut across **5 epic levels**, leaping from the Moon all the way to Earth. Built entirely in vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies, just open the page and play.

## 🎮 Play

The game is hosted via GitHub Pages. Open `docs/index.html` in any modern browser, or visit the live site:

**[▶ Play Lunar Dash](https://halomaster6482.github.io/studious-octo-computing-machine/)**

## 🕹️ Controls

| Input | Action |
|---|---|
| `←` / `→` Arrow Keys | Move left / right |
| `↑` Arrow Key or `Space` | Jump (tap again mid-air for double jump!) |
| Touch (mobile) | On-screen controls |
| Gamepad | Analog stick or D-pad + face button |

## 🌙 How to Play

- **Collect ⭐ stars** scattered across each level to build your score.
- **Reach the 🌀 portal** at the end of each level to advance.
- **Avoid 💀 red spikes** — they cost a life!
- You start with **3 lives ❤️**. Lose them all and it's Game Over.
- Clear all 5 levels to complete your journey from the **Moon → Earth** and earn the title of **Legendary Astronaut 🌍**.

## 🛠️ Running Locally

No build step required. Just open the file directly:

```bash
# Option 1 – open directly in your browser
open docs/index.html

# Option 2 – serve with any static server, e.g. Python
python3 -m http.server 8080
# then visit http://localhost:8080/docs/
```
